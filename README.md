## Code and results availability

The source code, analysis notebooks, article-ready results, and figures associated with this study are available in this GitHub repository:

https://github.com/hichamettajrini-lang/plant-domain-shift-reliability

The version used for the final manuscript has been archived on Zenodo:

https://doi.org/10.5281/zenodo.20358756

This archived release (`v1.2.0`) includes the qualitative high-confidence error figure and the stratified paired bootstrap confidence-interval analyses added for the final manuscript revision.

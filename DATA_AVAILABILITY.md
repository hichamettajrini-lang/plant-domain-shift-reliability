# Data availability

This repository does not redistribute PlantVillage, PlantDoc, or Plant Pathology 2020 images.

The result tables, figures, class-mapping outputs, and analysis summaries are provided to support transparency and reproducibility. Raw images should be downloaded from their official dataset sources and used according to their original licenses.

Model checkpoints are not included in the GitHub repository because of file size limits. They can be regenerated using the notebooks/scripts and may be archived separately on Zenodo if needed.

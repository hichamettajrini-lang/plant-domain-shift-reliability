# Notebooks

This folder contains the notebooks used to prepare the reliability-aware Edge-AI plant disease recognition study.

## Notebook overview

1. `01_dataset_exploration.ipynb`  
   Dataset exploration and initial inspection.

2. `03_uncertainty_calibration.ipynb`  
   Calibration and uncertainty analysis.

3. `04_decision_analysis.ipynb`  
   Decision-oriented analysis and false actuation risk.

4. `08_prepare_paper_figures.ipynb`  
   Preparation of article-ready figures.

5. `10_reliability_diagrams.ipynb`  
   Reliability diagrams and calibration curves.

6. `11_qualitative_error_analysis.ipynb`  
   Class-level and qualitative error analysis.

7. `paper_outputs.ipynb`  
   Final result aggregation and article-ready outputs.

## Important note

The notebooks may contain local paths from the original Windows project environment. Users should update paths according to their local dataset locations.

Raw datasets are not redistributed in this repository.

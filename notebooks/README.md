# Notebooks

The experiments were developed in Jupyter notebooks in the local project directory. To keep the GitHub package lightweight and free of local paths/dataset copies, this folder currently documents the notebook workflow rather than including all executed notebooks.

Suggested local notebook order:

1. Dataset exploration and binary mapping
2. Binary MobileNetV3/ResNet18 training
3. Calibration and decision-cost analysis
4. Multi-seed analysis
5. Fine-grained transfer learning with MobileNetV2, ResNet50, DenseNet121, and EfficientNetB0
6. PlantDoc external validation
7. Fine-tuning and augmented fine-tuning
8. Bootstrap confidence intervals
9. Grad-CAM explainability
